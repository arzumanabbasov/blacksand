# Support

Start with [setup](docs/SETUP.md), [operation](docs/OPERATIONS.md) and [testing](docs/VERIFICATION.md). Search [existing issues](https://github.com/arzumanabbasov/blacksand/issues) first.

Use the issue templates for reproducible bugs and focused proposals. Include the revision, platform, database and execution mode. Redact credentials and private target data.

Use [private reporting](https://github.com/arzumanabbasov/blacksand/security/advisories/new) for vulnerabilities. Community support has no uptime or response-time guarantee.
